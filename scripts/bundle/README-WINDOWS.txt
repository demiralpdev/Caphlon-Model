1. Double-click START-CAPHLON2.bat
2. First run downloads Caphlon-2-27B-PTQ1_SB.gguf (4.52 GiB) automatically into this folder.
3. Your browser opens automatically at http://127.0.0.1:8080 with the Chat UI (OpenAI API also live at http://127.0.0.1:8080/v1).
4. Requirements: Windows 10/11 64-bit + NVIDIA GPU (GTX 10/16, RTX 20/30/40/50 series, driver >= 551). No CUDA Toolkit or Python needed.
5. For terminal chat without browser UI, double-click CHAT-TERMINAL.bat.
